# ai-toolkit

Examples, skills and prompts for AI-assisted work. Workshop materials.

## Structure

```
ai-toolkit/
├── prompts/      # Reusable prompts and prompt templates
├── skills/       # Agent skills (e.g. for Claude Code)
├── examples/     # Example projects and code samples
└── workshops/    # Workshop materials, one folder per event
    └── 2026-08-19-claude-design/
```

### prompts/

Standalone prompts and prompt templates for common tasks. Each prompt lives in its own file with a short note on what it is for and how to use it.

### skills/

Agent skills that package instructions, scripts and resources into reusable capabilities. Each skill is a folder containing a `SKILL.md` plus any supporting files.

### examples/

Small, self-contained examples demonstrating AI-assisted workflows — from single scripts to complete mini-projects.

### workshops/

Materials for workshops and training sessions. Each event gets its own folder named `YYYY-MM-DD-topic`, containing slides, exercises and related resources.
